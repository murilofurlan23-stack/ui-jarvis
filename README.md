# J.A.R.V.I.S. – Interface Holográfica

Interface web inspirada no **J.A.R.V.I.S.** (Iron Man) com visual neon azul futurista, reconhecimento de voz, inteligência artificial e síntese de voz.

## ✨ Funcionalidades

- Interface holográfica inspirada no filme *Iron Man*
- Relógio e data em tempo real
- Status dos sistemas (propulsores, armadura, energia, etc.)
- Mapa global animado
- Painel de clima e notificações
- Controle de voz com microfone
- Chat interativo
- **LLM** via [Groq](https://groq.com) (Llama 3.3 70B)
- **Text-to-Speech** via [Fish Audio](https://fish.audio)
- Reconhecimento de voz nativo do navegador (Web Speech API)

---

## 🛠️ Tecnologias

| Tecnologia       | Uso                          |
|------------------|------------------------------|
| HTML5 + CSS3     | Interface e animações        |
| JavaScript       | Lógica e integrações         |
| Groq API         | Inteligência artificial      |
| Fish Audio API   | Voz sintetizada (TTS)        |
| Web Speech API   | Reconhecimento de voz (STT)  |
